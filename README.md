# Kornerstone Counselling Centre

Faith-based Christian counselling site for **kstonecc.org**.

## What this repo hosts

The public website for Kornerstone Counselling Centre — a Kornerstone Prophetic Ministry sister organisation offering confidential faith-based marriage, family, pre-marital, individual, and leadership counselling.

## Tech

- Static HTML/CSS/JS
- Deployed to Vercel from this repo (auto-deploy on push to `main`)
- Contact form via FormSubmit → kstone@kstonecc.org
- Session booking via Calendly
